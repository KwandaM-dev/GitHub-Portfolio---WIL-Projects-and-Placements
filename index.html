1. Project Overview

GoShuttle is a responsive Vue 3 web application for managing and tracking campus shuttle bus services. It provides live bus tracking, schedules, stop management, digital passes, and user authentication, built with a glass-morphism UI.

  • Tech stack: Vue 3 (Composition API), Vue Router 4, Vite, plain CSS, JavaScript (ES6+)
  • Scope: Frontend complete; Go backend API under development
  • Process: Agile — team charter, user stories, product & sprint backlogs, logbook

This portfolio presents the Agile artefacts and structured reflections required by the PRP370 assessment rubric (Evidence 10% + Reflection 10% per artefact).
