User Stories & Tasks

Artefact 2 of 5 · Evidence + Reflection (20 marks)

Each user story is written from the end-user's perspective and broken into concrete tasks. Stories are drawn from the GoShuttle feature set.

US-01 — Live Bus Tracking

As a student, I want to see the live progress and capacity of a shuttle so that I can decide whether to wait for it.
  • Task 1.1: Design the route-progress schematic UI.
  • Task 1.2: Bind capacity data to the tracking card.
  • Task 1.3: Add loading and empty states.
  • Task 1.4: Test responsiveness across mobile/tablet/desktop.

US-02 — Bus Schedules

As a commuter, I want to search and filter schedules by route, status, and departure time so that I can plan my trip.
  • Task 2.1: Build the filter bar (route, status, time).
  • Task 2.2: Implement expandable stop-by-stop cards.
  • Task 2.3: Wire the search input with debounce.

US-03 — Stops & Routes

As a student, I want to browse stops and set a preferred stop so that schedules default to what matters to me.
  • Task 3.1: List all stops and routes.
  • Task 3.2: Persist preferred stop selection.
  • Task 3.3: Add the banner linking to the schedule page.

US-04 — My Pass

As a staff member, I want a digital pass with usage stats so that I can present it and copy my pass ID quickly.
  • Task 4.1: Build the pass card with animated counters.
  • Task 4.2: Add copy-to-clipboard for the pass ID.
  • Task 4.3: Add copy confirmation feedback.

US-05 — Authentication

As a user, I want to sign in or register with real-time validation so that I can access my pass securely.
  • Task 5.1: Enforce CPUT email validation.
  • Task 5.2: Enforce password ≥ 8 characters.
  • Task 5.3: Add inline field validation messages.

US-06 — Responsive Glass UI

As a mobile user, I want the app to look and work well on my phone so that I can use it on the move.
  • Task 6.1: Shared sticky header and footer.
  • Task 6.2: Glass-morphism design tokens.
  • Task 6.3: Breakpoint testing.
